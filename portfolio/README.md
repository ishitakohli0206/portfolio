# Ishita Kohli — Portfolio

A production-ready developer portfolio built with Next.js, TypeScript, Tailwind CSS, and Framer Motion, generated from the attached resume.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm run start
```

## Deploy

This project is ready to deploy on [Vercel](https://vercel.com/new) — connect the repo (or drag-and-drop the folder) and it will build with zero configuration.

## Content

All content (experience, projects, skills, education, achievements) lives in a single file: `src/lib/data.ts`. Edit that file to update the site — no need to touch components.

## Resume file

Replace `public/Ishita_Kohli_Resume.pdf` with an updated resume at any time; the filename is referenced in `src/lib/data.ts` (`profile.resumeFile`).
